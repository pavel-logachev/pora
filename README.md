# Пора

**«Пора» напоминает принимать лекарства по расписанию и помнит, что вы уже приняли. Вносите курс, который назначил врач, — приложение пришлёт уведомление точно в срок, а отметить приём или пропуск можно прямо из уведомления.** Всё работает на телефоне без аккаунта и без интернета, включая встроенный справочник лекарств ЕСКЛП на 23 001 препарат.

## Что умеет

**Напоминает вовремя.** Несколько приёмов в сутки, необязательная дата окончания курса, быстрый выбор «до / во время / после еды». Уведомления построены на точных будильниках Android: расписание восстанавливается после перезагрузки телефона и пересчитывается при смене часового пояса.

**Помнит, что было.** Экран «Сегодня» показывает ближайший приём и прогресс дня. История хранит каждую отметку «принял» или «пропустил», её можно выгрузить в CSV. Приложение следит за остатком лекарства в аптечке.

**Подсказывает названия.** Встроенный офлайн-справочник ЕСКЛП Минздрава России (23 001 препарат, редакция от 29.07.2026) ищет по торговому названию и действующему веществу. Запрос «нурофен 200» поднимает наверх препараты с нужной дозировкой. Выбранный препарат сам подставляет дозировку, форму и единицу остатка; в аптечке видны МНН, форма, производитель и пометка ЖНВЛП. Название всегда можно ввести вручную.

**Работает без аккаунта.** Курсы и история хранятся на телефоне. Аккаунт нужен только для резервной копии и синхронизации между устройствами; его вместе с серверной копией можно удалить прямо из приложения.

Есть светлая и тёмная тема по настройке системы, крупные шрифты и зоны нажатия, подписи для специальных возможностей.

> Лечение назначает врач. «Пора» напоминает о приёмах, но не проверяет совместимость препаратов и не заменяет врача или инструкцию к лекарству.

## Установка

1. Откройте [страницу релиза 1.1.0](https://github.com/pavel-logachev/pora/releases/tag/v1.1.0).
2. Скачайте `Pora-1.1.0-android.apk` и лежащий рядом файл `.sha256`.
3. Если Android попросит, разрешите установку приложений из этого источника.
4. В настройках «Поры» разрешите уведомления и точные будильники.
5. На Xiaomi, Samsung и Huawei дополнительно проверьте ограничения батареи для приложения, иначе уведомления могут задерживаться.

> **Если у вас стоит версия 1.0.x.** Ключ подписи 1.0.x утрачен, и 1.1.0 подписана новым ключом, поэтому поверх старой версии она не установится. Перед удалением старой версии войдите в аккаунт «Пора» и дождитесь «Данные синхронизированы» — после установки 1.1.0 и входа в тот же аккаунт курсы, расписание и история вернутся. Можно также выгрузить историю в CSV. Данные без аккаунта хранятся только на телефоне и при удалении пропадут. Подробности — в [заметках к релизу](docs/release/RELEASE_NOTES_1.1.0.md).

## Приватность и безопасность

- Курсы и история хранятся на телефоне. Синхронизация с сервером включается только после создания аккаунта и идёт по HTTPS.
- Пароли хранятся на сервере как хеши Argon2id, код восстановления и refresh-токены — тоже только хешами. Токены ротируются, сессия на телефоне лежит в защищённом хранилище.
- Справочник ЕСКЛП работает локально и на сервер не отправляется.
- Нет рекламы, рекламного профилирования и записи звука. Приложение запрашивает только уведомления, точные будильники, запуск после перезагрузки и вибрацию; разрешения на общее хранилище телефона заблокированы.
- Ключи подписи APK и рабочие учётные данные в репозиторий не входят.

## Как устроено

Приложение на React Native и Expo:

- доменная модель и репозиторий на локальной SQLite;
- справочник ЕСКЛП — встроенная SQLite-база с полнотекстовым поиском FTS5, версия и размер проверяются при открытии;
- планировщик уведомлений, сверка расписания и нативный модуль точных будильников Android;
- единая светлая и тёмная тема в `src/ui/theme.ts`;
- защищённое хранилище сессии и необязательный клиент синхронизации по HTTPS.

Сервер синхронизации на Fastify и PostgreSQL: аутентификация Argon2id, ротация JWT, идемпотентный поток событий.

Подробности — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Запуск из исходников

Нужны Node.js 24, npm, Android SDK и JDK 21.

```bash
npm ci
npm run typecheck
npm test -- --runInBand
npx expo-doctor
npm run android
```

Подписанная релизная сборка (ключ и пароль берутся из каталога вне репозитория, см. заголовок скрипта):

```bash
python scripts/build-android-release.py
```

Предпросмотр в браузере: `npm run web`.

Сервер синхронизации:

```bash
cd backend
cp .env.example .env
npm ci
npm run migrate
npm run dev
```

Нужны PostgreSQL и собственный `JWT_SECRET` длиной не меньше 32 символов. Рабочих секретов в репозитории нет.

## Проверка

Релиз 1.1.0:

- приложение: 21 набор Jest, 78 тестов, включая поиск по реальному файлу справочника, миграции и синхронизацию ссылки на справочник; проверка TypeScript; Expo Doctor 21/21;
- подписанный APK 1.1.0 (6): `apksigner verify`, APK Signature Scheme v2, RSA 3072; установка и запуск на эмуляторе Android 16, работа справочника, светлая и тёмная тема.

Код уведомлений не менялся с линии 1.0.2, для которой ранее подтверждены:

- сервер: 2 набора Vitest, 8 тестов, проверка TypeScript и рабочая сборка;
- чистая установка и обновление на эмуляторе Android 16;
- точные будильники в принудительном глубоком Doze, действия из уведомления и восстановление после перезагрузки;
- системный выбор времени и даты, несколько приёмов в сутки, отмена незавершённого выбора;
- рабочие `/health`, страницы конфиденциальности и условий.

CI при каждом push и pull request в `main` проверяет типы, тесты и Expo Doctor приложения, а также типы, тесты и сборку сервера.

## Структура

- `src/` — домен, данные, справочник, интерфейс, уведомления и синхронизация приложения;
- `modules/pora-device-settings/` — нативная интеграция точных будильников Android;
- `backend/` — сервис синхронизации на Fastify и PostgreSQL;
- `scripts/` — проверка рабочего сервиса и `build-android-release.py`;
- `docs/` — архитектура, скриншоты и подтверждения релизов.

## Ограничения

- Приложения нет в Google Play, установка — из APK.
- iOS указан в настройках Expo, но сборка и приёмка для iOS не проверены.
- Доставка уведомлений зависит от настроек батареи в оболочке производителя.
- «Пора» не является медицинским изделием.
